GenMSI 0.3.2 — simulador GPSS
================================

Esta carpeta lleva la aplicación para Linux (x86_64), sin instalar.

CÓMO SE USA
-----------
1. Dale permiso de ejecución al programa:

       chmod +x genmsi-app-desktop

2. Ábrelo con un doble clic, o desde una terminal:

       ./genmsi-app-desktop

La ventana se titula "GenMSI". Desde la barra de herramientas se abre un
modelo («Abrir…»), se guarda («Guardar» y «Guardar como…») y se corre la
simulación («Simular» para el informe, «Ejecutar» para verla reproducida).

La simulación corre una sola vez: la reproducción y el informe salen de esa
misma corrida, así que los números que ves son los de esa corrida ✓. Se
puede interrumpir con «Cancelar», y el informe dice que la corrida se
cortó.

QUÉ NECESITA
------------
Un escritorio Linux con GTK 3 y WebKitGTK 4.1 (los tiene cualquier
distribución de escritorio: Debian, Ubuntu, Fedora, openSUSE, Arch, CachyOS...).

Para instalarlo como un programa del sistema, mejor el paquete:
  - Debian, Ubuntu y derivados:  GenMSI_0.3.2_amd64.deb   (sudo dpkg -i)
  - Fedora, openSUSE y derivados:  GenMSI-0.3.2-1.x86_64.rpm
  - CachyOS, Arch y derivados:  genmsi-0.3.2-1-x86_64.pkg.tar.zst
    (sudo pacman -U)

QUÉ SE PUBLICA
--------------
Estos son los formatos de cada versión, todos con el mismo número:
  - GenMSI_0.3.2_amd64.deb             Debian y Ubuntu (x86_64)
  - GenMSI_0.3.2_arm64.deb             Debian y Ubuntu (aarch64)
  - GenMSI-0.3.2-1.x86_64.rpm          Fedora y openSUSE (x86_64)
  - GenMSI-0.3.2-1.aarch64.rpm         Fedora y openSUSE (aarch64)
  - genmsi-0.3.2-1-x86_64.pkg.tar.zst  CachyOS y Arch (x86_64)
  - GenMSI_0.3.2_universal.dmg         macOS (Intel y Apple Silicon)
  - GenMSI_0.3.2_x64-setup.exe         Windows (x64)
  - GenMSI_0.3.2_x64_en-US.msi         Windows (x64)
  - GenMSI_0.3.2.flatpak               Flatpak
  - GenMSI-0.3.2-linux-x86_64.tar.gz   la versión portátil, sin instalar
  - SHA256SUMS                         la suma de cada instalador

QUÉ HAY DENTRO
--------------
  genmsi-app-desktop   la aplicación (el motor va dentro: no hace falta nada más)
  GenMSI.desktop       el lanzador, por si quieres ponerlo en el menú
  GenMSI.png           el icono
  LEEME.txt            este archivo

Los modelos que abras son tuyos: la aplicación no borra ni toca nada fuera de
la carpeta de datos del usuario, donde guarda la lista de los últimos modelos
abiertos.
